## 2. 明确缺口

| # | 缺口 | 影响 | 建议 |
|---|---|---|---|
| 1 | **FactoryBean** | Spring IoC 重要机制；README 写了 `ch15-factorybean`，实际没有 | 读 BeanFactory/BPP 前补 |
| 2 | **SpEL** | `@Value`、缓存、条件等大量使用 | 读 Environment/Configuration 后补 |
| 3 | **MockMvc** | 测试切片核心 | 读 Spring MVC 后补 |
| 4 | **TestContext** | 测试上下文/切片基础 | 与 MockMvc 一起补 |
| 5 | **ApplicationContext 完整生命周期** | refresh 之外还有 close/destroy | 读 refresh 后补 |
| 6 | **BeanFactory 销毁/回收** | 生产资源释放/优雅停机 | 与生命周期一起补 |
| 7 | **运行时诊断** | 循环依赖/AOP/事务/条件不生效 | 读 AOP/TX 后补 |
| 8 | **启动/运行性能** | P7/P8 性能追问 | 读完 Boot 后补 |
| 9 | **WebFlux 框架级** | 网关/响应式治理 | 读 Spring MVC 后补 |

补充：

- `vol-spring` README 的“当前只完成 1 篇”是旧状态，实际 55 篇正文；
- `vol-spring-boot` README 只列到 23 篇，实际有 37 篇；
- 版本基线不完全统一：`vol-spring` 以 Spring Framework 6.2.x 为主，Boot 卷部分以 3.5.x/6.2.x 为主；如果对照 Boot 3.2.5/6.1.x，行号会有差异，学习时先定一个基线；
- Spring Cloud Gateway 不在本套里，网关专题另有独立文档。

## 4. 第一篇

```text
/data/workspace/source-code/xhs-demo/docs/tmp-question/openjdk-book/07-主流框架源码/vol-spring/ch01-core-resource-01-resource-abstraction.md
```

读法：

1. 先看“为什么不能直接用 File/URL”；
2. 追 `Resource → AbstractResource → 具体实现 → ResourceLoader`；
3. 对照 Spring 源码中的 `Resource` 接口和实现；
4. 记下“Spring 为什么把资源抽象成协议”；
5. 不急着看所有实现类，先走通一条链。

## 5. 结论

- **可以开始读第一篇**；
- 9 个缺口不阻塞主线，按阅读阶段补；
- 不要把 `spring-kernel` 8 篇压缩版当主线，它适合复习，不适合打底；
- 版本基线先定：Spring Framework 6.2.x + Boot 3.5.x，或项目实际的 Boot 3.2.5/6.1.x，二者不要混。
