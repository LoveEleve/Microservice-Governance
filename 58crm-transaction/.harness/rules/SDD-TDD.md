# SDD + TDD 规则

## 1. 规格真相源

每个变更一个 `change.md`：

```text
用户故事
Out of Scope
验收条件 AC
边界情况
非功能需求
设计约束
契约影响
测试策略
验收用例
```

没有 `change.md` 的核心逻辑变更不得开始实现。

## 2. TDD

核心逻辑默认：

```text
Red     先写失败测试
Green   最小实现
Refactor 测试保护下重构
```

必须测试先行：

```text
TCC 状态迁移
空回滚/悬挂/幂等
消息状态迁移
重试与对账
```

可弱化：

```text
DTO
配置类
纯装配代码
```

## 3. 完成定义

```text
AC 全部有测试
编译通过
单测通过
集成测试通过
文档同步
```

不允许：

```text
先写完整实现再补核心测试
用覆盖率代替测试先行
只测 happy path
```
