# C-003.7 真实 E2E Review

> 审查对象：Nacos + MySQL + Coordinator + lead + quota 真实进程。
> 结论：成功链路和 Try 失败链路都跑通。

## 1. 环境

```text
nacos-e2e      v2.3.2 standalone
mysql-p9       8.0
coordinator    9090
lead-service   8081
quota-service  8082
quota gRPC     9092
```

## 2. 链路

```text
lead -> TC gRPC
lead -> quota OpenFeign
TC -> quota gRPC callback
```

## 3. 成功

```text
POST /leads/1001/assign?userId=1
-> CONFIRMED
```

结果：

```text
quota assigned=1
global CONFIRMED
branch CONFIRMED
barrier CONFIRMED
outbox INIT
```

## 4. 失败

```text
POST /leads/1001/assign?userId=999
-> CANCELLED（公共模板返回 rollback 后状态）
```

结果：

```text
global CANCELLED
branch CANCELLED
barrier SUSPENDED
quota 未扣减
```

## 5. Review 发现

### P0：Nacos Config 缺少 config.import

已补：

```text
optional:nacos:${spring.application.name}.yml
```

### P0：Participant Starter BarrierMapper 未注册

真实服务启动时 `SqlSessionTemplate.getMapper` 失败：

```text
BarrierMapper is not known to the MybatisPlusMapperRegistry
```

处理：

```text
MapperScan 扫描 barrier 包
删除重复的 tccBarrierMapper Bean
```

### P1：OutboxPublisher 自动装配依赖顺序

quota 显式装配：

```text
BizCodeRegistry
LocalBizCodeRegistry
MybatisOutboxPublisher
```

### P1：Controller 参数名

`@PathVariable/@RequestParam` 显式写参数名，避免 `-parameters` 依赖。
