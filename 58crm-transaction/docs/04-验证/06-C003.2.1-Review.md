## 2. 关键修复

### P0：并发 Begin 的快照读

问题：

```text
REPEATABLE READ 下失败方普通 SELECT 可能看不到胜者
```

处理：

```text
唯一键冲突后改用 SELECT ... FOR UPDATE 当前读
8 线程并发 Begin 测试通过
```

### P0：branch_seq 并发分配

处理：

```text
RegisterBranch 先锁 global 行
再 branchId = branch_seq + 1
再更新 global.branch_seq
8 线程并发注册 branchId 唯一
```

### P1：ReportBranch 覆盖二阶段

处理：

```text
UPDATE 只允许 branch TRYING + global TRYING
已进入 CONFIRMING/CANCELLING 后不能落 Try 结果
```
