# C-005.5 包边界 Review

> 审查对象：低层 DTO 迁移、protocol model、crm-tx-bom、公共 api 收敛。
> 结论：公共 api 只保留业务契约；内部协议 DTO 进入 protocol 模块。

## 1. 移动结果

从 `crm-tx-tcc-api` 移到 `crm-tx-tcc-protocol`：

```text
com.wuba.crm.tx.tcc.protocol.model
  TccBeginRequest / TccBeginResult
  TccBranchRegisterRequest / TccBranchRegisterResult
  TccBranchReportRequest
  TccCommitResult / TccRollbackResult
  TccQueryResult / TccBranchInfo
  TccCallbackResult
```

公共 `crm-tx-tcc-api` 保留：

```text
TccRequest / TccBranchSpec / TccResult / TccBranchResult
TccAction / TccActionHandler / TccPhaseResult
TccTransactional / TccBranch / TccContext
TccTransactionTemplate
GlobalStatus / BranchStatus / BarrierStatus
TccException / TccResultCode
```

## 2. 模块依赖

```text
crm-tx-tcc-protocol -> crm-tx-tcc-api
crm-tx-tcc-client -> protocol + api
crm-tx-tcc-coordinator -> protocol + api
crm-tx-tcc-participant -> protocol + api
```

没有反向依赖；api 不再引用 protocol。

## 3. BOM

新增：

```text
crm-tx-bom
```

统一管理：

```text
crm-tx-common
crm-tx-tcc-api / protocol / client / participant / id / coordinator / starter
crm-tx-outbox / consumer / starter
```

业务方不再复制 `<version>0.1.0-SNAPSHOT</version>`。
