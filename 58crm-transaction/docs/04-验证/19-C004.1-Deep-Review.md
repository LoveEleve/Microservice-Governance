# C-004.1 深度 Review

> 审查对象：TccRequest/TccBranch/TccResult/DefaultTccTransactionTemplate。
> 结论：公共模板语义可用；协议和 Starter 仍是下一阶段。

## 1. 已修正

### P1：重复 resourceKey

同一请求出现两个相同 resourceKey 会在 Coordinator 唯一键冲突，应该提前拒绝。

已加：

```text
TccRequest 构造时检查 resourceKey 唯一
```

### P1：begin/register 状态未校验

模板新增：

```text
begin 必须返回 TRYING
register 必须返回 TRYING
否则 TCC_INVALID_STATE
```

## 2. 当前语义

```text
先 begin
再注册全部分支
再按顺序 Try
每个 Try 后 report
全部成功 commit
任一失败 rollback
```

失败：

```text
Try FAILURE -> report TRY_FAIL + rollback
Try 异常 -> report TRY_FAIL + rollback
register 失败 -> rollback + 抛异常
```

## 3. 仍需注意

```text
TccResult.branches.status 是 Try 阶段状态
不是 Confirm 后最终状态
```

需要最终状态时用 Query。
