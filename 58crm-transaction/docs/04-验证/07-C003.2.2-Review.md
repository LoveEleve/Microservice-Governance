## 4. Spring 装配

### P0：@MapperScan 误把 Repository 接口注册成 Mapper

发现：

```text
@MapperScan 扫描整个 persistence 包
TccGlobalRepository / TccBranchRepository 也被当成 Mapper
同时 @Repository 实现已存在
结果出现两个同类型 Bean
```

修复：

```text
@MapperScan(annotationClass = Mapper.class)
只扫描显式 @Mapper 接口
```

这是 `TccCoordinatorApplicationTest` 发现的真实启动失败问题。

```text
@MapperScan(coordinator.persistence + tcc.id, annotationClass=Mapper.class)
@EnableTransactionManagement(proxyTargetClass = true)
Clock.systemUTC()
MybatisSegmentAllocator
SegmentIdGenerator
TccXidGenerator
```

为什么 proxyTargetClass：

```text
MybatisSegmentAllocator 有 @Transactional
按具体类型注入时需要 CGLIB 代理
```
