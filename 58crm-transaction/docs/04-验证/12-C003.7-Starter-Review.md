# C-003.7 Starter Review

> 审查对象：Participant Starter 自动装配。
> 结论：自动装配可用；Nacos/Sentinel/metrics 仍待接入。

## 1. 验证

```text
mvn -q test
tests=198 failures=0 errors=0 skipped=1
```

## 2. 自动装配

```text
TccActionRegistry
BarrierRepository
TccParticipantService
TccParticipantCallbackGrpcService
TccParticipantGrpcServer
```

条件：

```text
crm.tx.enabled
crm.tx.tcc.participant.enabled
BarrierMapper 存在
```

## 3. 测试

```text
CrmTxTccParticipantAutoConfigurationTest 3
  autoConfiguresParticipantInfrastructure
  autoCreatesBarrierMapperFromSqlSessionTemplate
  disabledPropertyStopsAutoConfiguration
```

## 4. Review 发现

### P1：@ConditionalOnBean 不能依赖业务 @MapperScan 的时序

原实现直接要求 `BarrierMapper` Bean，可能受 MapperScan 注册时序影响。

已改为：

```text
存在 SqlSessionTemplate -> Starter 自动创建 BarrierMapper
否则要求业务显式提供 BarrierMapper
```

### P1：事务代理

AutoConfiguration 补：

```text
@EnableTransactionManagement(proxyTargetClass = true)
```

避免 TccParticipantService 的 @Transactional 失效。

## 5. 边界

```text
不自动扫描业务 Mapper 包
不自动注册业务 TccAction
不接 Nacos/Sentinel/metrics
```

## 5. 一句话

> **Starter 只装配框架组件；Mapper 扫描和业务动作注册仍由业务显式完成。**
