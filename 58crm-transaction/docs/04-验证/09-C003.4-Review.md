## 3. 关键事务语义

```text
Try:
  INSERT TRIED + action.tryAction 同一事务
  失败 rollback-only

Confirm:
  lock TRIED
  action.confirmAction
  barrier CONFIRMED
  同一事务

Cancel:
  无 barrier -> INSERT SUSPENDED
  TRIED -> action.cancelAction + CANCELLED
  同一事务
```

## 4. 三防

```text
重复 Try -> 幂等
重复 Confirm -> 幂等
重复 Cancel -> 幂等
Cancel 先到 -> SUSPENDED
迟到 Try -> FAILURE
Confirm 后 Cancel -> INVALID_STATE
```

### P1：空回滚不能接受未知 action

Cancel 无 barrier 时先校验 action 是否存在，避免错误 action 抢先写 SUSPENDED，导致真正的 Try 被悬挂。

## 5. Outbox 边界

```text
框架不生成业务事件
业务 TccAction.confirmAction 在 Confirm 事务内调用 OutboxPublisher
框架只保证 barrier、业务动作、Outbox 同一本地事务
```

## 6. 一句话

> **barrier 和业务动作必须同本地事务；Try 失败不能留下 TRIED，Cancel 先到必须留下 SUSPENDED，Confirm/Cancel 锁行保证只选择一个终态。**
