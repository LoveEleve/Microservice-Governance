# C-003.3 Review

> 审查对象：Commit / Rollback / Query、owner lease、RM callback。
> 结论：二阶段主链路可运行；barrier 和自动重试留到后续切片。

## 1. 验证

```text
mvn -q test
tests=190 failures=0 errors=0 skipped=1
```

## 2. 已落地

```text
TccPhase2Coordinator
TccParticipantClient
GrpcTccParticipantClient
Commit / Rollback / Query gRPC adapter
owner_token / lease_until
branch 预推进
transitionOwned 带 lease fencing
```

## 3. 关键设计

```text
DB 事务：
  owner claim
  global 状态推进
  branch 预推进
  branch 终态更新

事务外：
  RM Confirm/Cancel
```

原因：

```text
RM 网络调用不能持有 global 行锁
```

## 4. 发现并修正

### P0：终态更新缺 lease fencing

`transitionOwned` 原来只校验 owner_token，没有校验 lease_until。

已补：

```sql
AND lease_until > #{now}
```

否则旧 owner 在 lease 过期后仍可能写终态。

### P0：callback 锁内执行

实现上把 RM 回调放在 TransactionTemplate 外：

```text
prepare transaction -> commit
confirm/cancel callbacks
mark/finalize transaction
```

避免网络 I/O 持有行锁。

### P1：owner 续租

每次回调前续租：

```text
renewOwner(xid, owner, now + 30s, now)
```

续租失败停止推进。

### P1：永久失败

```text
branch DEAD
global FAILED
```

可重试失败：

```text
保持 CONFIRMING/CANCELLING
等待 C-003.6 Scheduler
```

### P1：终态 update 必须检查影响行数

`finalizeStatus` 和永久失败分支已检查 `transitionOwned` 返回值：

```text
影响 0 行 -> 返回当前状态，不假装 CONFIRMED/CANCELLED
```

### P1：非法 callback endpoint

```text
host/port 解析失败 -> PERMANENT_FAILURE
不进入无限 retry
```

测试：

```text
GrpcTccParticipantClientTest 5
TccCoordinatorServiceTest 23
```

### P1：finalize 不能假定终态一定写入

`finalizeStatus` / 永久失败路径已检查 `transitionOwned` 影响行数：

```text
0 -> 返回当前状态，等待新 owner/重试
1 -> 才返回 CONFIRMED/CANCELLED/FAILED
```

### P1：非法 endpoint

`GrpcTccParticipantClient` 将 endpoint 解析失败映射为：

```text
PERMANENT_FAILURE
```

不进入无限 retry。

## 5. 当前限制

```text
Cancel 成功未区分 CANCELLED / SUSPENDED
每次 callback 新建 channel
没有自动重试调度
没有 barrier/Outbox
没有 TLS/鉴权
没有真实 RM 集成测试
```

## 6. 一句话

> **二阶段先锁 DB 推状态，再在锁外回调 RM；owner + lease 防止旧 TC 覆盖，retryable 暂时停在 CONFIRMING/CANCELLING，等待 Scheduler。**
