# C-004.4 Review

> 审查对象：独立 TCC Starter。
> 结论：TCC 已从通用 Starter 拆出；client/participant 可独立开关。

## 1. 新模块

```text
crm-tx-tcc-spring-boot-starter
  CrmTxTccProperties
  CrmTxTccClientAutoConfiguration
  CrmTxTccParticipantAutoConfiguration
  CrmTxTccBarrierMapperConfiguration
```

## 2. 配置

```yaml
crm:
  tx:
    tcc:
      client:
        enabled: true
        coordinator-service-name: crm-tx-tcc-coordinator
        coordinator-address:
        deadline-seconds: 15
      participant:
        enabled: true
        grpc-enabled: true
        grpc-port: 9091
        try-endpoint-enabled: true
```

## 3. 自动装配

client：

```text
DiscoveryClient -> DiscoveryTccCoordinatorEndpointProvider
无 discovery -> coordinator-address 直连
DefaultTccTransactionTemplate
```

participant：

```text
TccActionRegistry
TccActionRegistrar
BarrierRepository
TccParticipantService
TccParticipantTryController
TccParticipantCallbackGrpcService
TccParticipantGrpcServer
```

## 4. 边界

```text
通用 crm-tx-spring-boot-starter 不再包含 TCC
TCC 使用 crm-tx-tcc-spring-boot-starter
```

## 5. 测试

```text

tests=213 failures=0 errors=0 skipped=1
```

## 6. 一句话

> **TCC 现在有独立 Starter，业务方不再被 Outbox/Consumer 配置绑架。**
