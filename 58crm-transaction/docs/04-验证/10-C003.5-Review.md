# C-003.5 Review

> 审查对象：Confirm 事务契约、业务 Outbox 示例、回滚测试。
> 结论：边界正确；框架不生成业务事件。

## 1. 验证

```text
mvn -q test
tests=197 failures=0 errors=0 skipped=1
```

新增：

```text
TccOutboxTransactionTest 2
```

## 2. 正确性

成功：

```text
业务状态 ASSIGNED
barrier CONFIRMED
t_local_message 1 条 INIT
```

回滚：

```text
业务状态 ASSIGNING
barrier TRIED
t_local_message 0 条
```

## 3. 边界

```text
TccParticipantService:
  transaction + barrier

TccAction.confirmAction:
  business final state + OutboxPublisher.publish

OutboxPublisher:
  @Transactional(MANDATORY)
  复用 Confirm 事务
```

## 4. 明确不做

```text
框架自动推断 eventKey
框架自动生成 eventType
框架自动拼 payload
```

## 5. 一句话

> **Confirm 的 Outbox 是业务动作的一部分；框架只提供事务壳和 barrier，不替业务生成事件。**
