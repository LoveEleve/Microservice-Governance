# C-003.7 Nacos Review

> 审查对象：Nacos 依赖、Coordinator gRPC 注册、默认关闭策略。
> 结论：本地默认不影响测试；真实 Nacos 未跑。

## 1. 验证

```text
mvn -q test
tests=200 failures=0 errors=0 skipped=1
```

## 2. 关键决定

```text
spring.cloud.nacos.discovery.enabled=false
TccCoordinatorNacosRegistrar 显式注册 gRPC 端口
metadata.protocol=grpc
```

原因：

```text
Coordinator 没有 Web 容器
默认 Web 注册不会触发
```

## 3. 配置发现的问题

Nacos Config 依赖要求：

```text
spring.config.import
```

已配置：

```text
optional:nacos:${spring.application.name}.yml
```

避免“未设置 config import”启动失败。

## 4. 当前限制

```text
没有真实 Nacos Server 测试
没有配置热更新测试
没有 Nacos 权重/灰度
Sentinel 未接
```

## 5. 一句话

> **Nacos 默认关闭，生产显式开启；Coordinator 按 gRPC 端口注册，不依赖 Web 端口。**
