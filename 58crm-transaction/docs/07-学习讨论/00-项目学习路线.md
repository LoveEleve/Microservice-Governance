# 项目学习路线

> 目标：不从 Coordinator 内部开始，先看一条真实业务链路，再进入状态机和源码。

## 1. 第一轮：业务链路

```text

  LeadAssignService
  TccCoordinatorClient
```

```text
begin
  -> registerBranch
  -> OpenFeign Try
  -> report TRY_SUCCESS
  -> commit
  -> gRPC Confirm
  -> barrier CONFIRMED
```


## 4. 第四轮：故障实验

```text
停掉 quota -> Try 失败
Try 成功后停掉 TC -> Scheduler 接管
重复 Confirm -> barrier 幂等
Confirm 返回 RETRYABLE -> next_retry_at 退避
Cancel 先到 -> SUSPENDED
迟到 Try -> FAILURE
```

## 5. 不要从这里开始

```text
不要先读 TccPhase2Coordinator 的全部私有方法
不要先读 proto 生成代码
不要先读 Nacos 注册细节
不要从旧的 docs/05-代码讲解/00-代码地图.md 的“TCC 后续”描述开始
```

## 6. 一句话

> **从 `/leads/{leadId}/assign` 的业务入口开始，先成功链路，再失败链路，最后状态机。**
