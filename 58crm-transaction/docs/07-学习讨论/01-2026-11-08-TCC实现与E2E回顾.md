## 3. 关键设计结论

### 3.1 TCC 控制流

```text
TM -> TC：gRPC unary
TC -> RM：gRPC unary callback
TM -> RM Try：业务 API / OpenFeign
TC 不发现 RM
```

### 3.2 XID

```text
XID 用项目内号段生成
不复用
XID > 0
branchId = global.branch_seq
```

### 3.3 Barrier

```text
Try       -> TRIED
Confirm   -> CONFIRMED
Cancel    -> CANCELLED
Cancel 先到 -> SUSPENDED
迟到 Try  -> 拒绝
```

### 3.4 Outbox 边界

```text
框架只提供 Confirm 本地事务和 barrier
业务 TccAction.confirmAction 写业务终态 + OutboxPublisher.publish
框架不生成 eventKey/eventType/payload
```

### 3.5 重试

```text
调用级短重试：2~3 次，不增加 retry_count
持久化重试：branch.next_retry_at + Scheduler + retry_count
达到上限：branch DEAD / global FAILED
```

### 3.6 owner lease

```text
一个 xid 一个 owner
所有二阶段更新校验 owner_token + lease_until
旧 owner 不能覆盖新 owner
```

## 4. 真实 E2E

环境：

```text
Nacos 2.3.2 standalone
MySQL 8.0
coordinator 9090
lead-service 8081
quota-service 8082
quota gRPC 9092
```

成功：

```text
POST /leads/1001/assign?userId=1
-> {"xid":1,"status":"CONFIRMED"}

quota assigned=1
global CONFIRMED
branch CONFIRMED
barrier CONFIRMED
t_local_message INIT
```

Try 失败：

```text
POST /leads/1001/assign?userId=999
-> {"xid":2,"status":"TRY_FAIL"}

global CANCELLED
branch CANCELLED
barrier SUSPENDED
quota 未扣减
```
