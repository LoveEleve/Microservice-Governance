## 写作约定

```text
使用文档：只讲怎么用，不展开内部类
设计文档：讲职责和边界，不贴大段代码
数据文档：讲表、键、状态、分片
验证文档：讲 AC、测试用例、运行命令
代码讲解：按调用链讲具体类
变更文档：只讲本次范围和验收
```
