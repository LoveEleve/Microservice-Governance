## 3. 文档中的冲突

| 冲突 | 说明 |
|---|---|
| 86 个消费组 vs Redis List | List 没有 consumer group；只能单组消费 |
| 消息表本地 vs 中心 | 文档既说同库同事务，又说只由消息服务写 |
| payload 在 MySQL vs Redis | 文档两处说法相反 |
| Redis ZSet 延迟队列 vs DB next_retry | 实现路线不同 |
| `t_tx_message_log` 多消费组多行 vs 单组 | 与 List 模型冲突 |
| 批量 64 vs 500 | 一期/二期不同口径，需按版本区分 |
| 消费回执更新状态 vs 消费方不写生产方库 | 缺少 ACK 归属 |

处理原则：

```text
业务承诺优先
硬约束优先
数字按二期生产口径
冲突项必须显式决策并记录
不能一边说 List，一边说多消费组
```
