# 代码地图

> 读完你能做什么：知道源码从哪个入口开始读，先看成功链路还是失败链路。

## 1. 模块

```text
tx-common
  状态枚举、上下文、错误码、ID 生成

tx-coordinator
  TCC 协调器、状态机、恢复调度

tx-participant
  @TccParticipant、TccAction、barrier

tx-outbox
  OutboxPublisher、Scanner、Buffer、Sender、Stream、Consumer、幂等

tx-demo
  线索分配示例
```

## 2. 阅读顺序

```text
先看 tx-demo 的入口
→ 看参与者 TccAction
→ 看协调器状态机
→ 看 Outbox/Relay/Consumer
→ 看对应测试
```

## 3. 成功链路

```text
LeadAssignService.assignLead
  → TccTransactionTemplate.execute
  → LeadTccAction.tryAction
  → QuotaTccAction.tryAction
  → Coordinator.confirm
  → LeadTccAction.confirmAction
  → OutboxPublisher.publish
  → OutboxScanner
  → OutboxBuffer
  → OutboxSender
  → Redis Stream
  → StreamConsumer
```

## 4. 失败链路

```text
Try 失败
  → Coordinator.cancel
  → LeadTccAction.cancelAction
  → QuotaTccAction.cancelAction

Confirm 超时
  → RecoveryScheduler
  → retry confirm

消费者崩溃
  → Stream PEL
  → XCLAIM/XAUTOCLAIM 重试

重复消息
  → IdempotentRepository
```
