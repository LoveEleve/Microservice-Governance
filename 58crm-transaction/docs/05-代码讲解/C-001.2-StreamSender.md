# C-001.2 代码讲解：Stream 发送端

> 读完你能做什么：说清 MySQL Outbox 如何经过扫描线程、有界 buffer、独立发送线程写入 Redis Stream，以及 Kafka 式扩展点在哪里。

## 1. 结构

```text
OutboxScanner
  → OutboxBuffer（有界）
  → OutboxSender
      → OutboxInterceptorChain.onSend
      → OutboxPartitioner
      → OutboxSerializer
      → RedisStreamPublisher
      → OutboxInterceptorChain.onAcknowledgement
  → LocalMessageRepository.markSentBatch
```

## 2. 类清单

| 类 | 作用 |
|---|---|
| `OutboxScanner` | 扫 MySQL，放入 buffer，不发送 |
| `OutboxBuffer` | 有界内存队列，背压 |
| `OutboxInFlight` | 防止扫描重复入队 |
| `OutboxSender` | 独立发送线程核心 |
| `OutboxProducer` | 扫描线程 + 发送线程生命周期 |
| `OutboxConfig` | 窗口、批次、buffer、扫描参数 |
| `OutboxRecord` | 发送线程使用的不可变消息 |
| `OutboxInterceptor` | onSend / onAcknowledgement |
| `OutboxInterceptorChain` | 有序、异常隔离的拦截器链 |
| `OutboxPartitioner` | bizCode → Stream |
| `OutboxSerializer` | record → Stream fields |
| `RedisStreamPublisher` | Stream 写入端口 |
| `RedisStreamPublisherAdapter` | XADD pipeline |

## 3. 为什么拆扫描和发送

旧结构：

```text
每 10ms 扫 MySQL
→ 当场 XADD
→ 当场 markSent
```

问题：

```text
DB 扫描被 Redis 延迟拖慢
Redis 抖动直接顶住扫描
没有内存缓冲/背压
```

新结构：

```text
Scanner 只负责 DB → buffer
Sender 只负责 buffer → Redis/MySQL
```

任一侧变慢，有界 buffer 形成背压。

## 4. 窗口/批量

```text
OutboxConfig：
  linger = 10ms
  batchSize = 256
  bufferCapacity = 50_000 条
  bufferCapacityBytes = 64MB
  scanBatch = 1_000
  retryAfter = 30s
  maxRetries = 5
```

发送线程：

```text
poll 第一条
→ 等 linger 窗口，继续取同 bizCode
→ 最多 batchSize
→ XADD pipeline
```

## 5. 状态推进

```text
INIT → SENT → DEAD
```

规则：

```text
扫描/入 buffer：状态不变
XADD 成功：markSentBatch，INIT -> SENT（终态）
XADD/序列化/路由失败：markFailedBatch
  重试计数 + 1
  超过上限 -> DEAD
```

不能：

```text
入 buffer 就标 SENT
SENT 超时再次 XADD
XADD 失败不计数
生产方写 CONSUMED
```

## 6. 扩展点

```java
public interface OutboxInterceptor {
    OutboxRecord onSend(OutboxRecord record);
    void onAcknowledgement(OutboxSendResult result, Throwable error);
    default void close() {}
}
```

用途：

```text
traceId
租户
schema 版本
加密
采样
审计
指标
灰度
```

链式规则：

```text
按配置顺序
前一个返回的 record 传给下一个
异常只记录，不阻断发送
onAcknowledgement 在发送线程执行，必须快
```

## 7. Redis Stream

```text
stream: tx:stream:{bizCode}
group:  tx-group-{bizCode}
```

生产：

```text
XADD
XGROUP CREATE ... MKSTREAM
```

消费（C-001.3）：

```text
XREADGROUP
XACK
XPENDING
XAUTOCLAIM（Redis 7）
```
