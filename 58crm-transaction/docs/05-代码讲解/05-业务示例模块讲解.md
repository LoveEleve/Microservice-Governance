## 2. `application.yml`

```yaml
tx:
  stream-prefix: "tx:stream:"
  biz-codes:
    - lead
    - quota
  outbox:
    linger: 10ms
    batch-size: 256
    buffer-capacity: 50000
    buffer-capacity-bytes: 67108864
    scan-batch: 1000
    scan-interval: 10ms
    retry-after: 30s
    max-retries: 5
    sender-threads: 8
```

这是业务方自己的配置文件，不是框架内置配置。

## 3. `DemoProperties`

| 方法 | 作用 |
|---|---|
| `getStreamPrefix/setStreamPrefix` | Stream key 前缀 |
| `getBizCodes/setBizCodes` | 业务白名单 |
| `getOutbox/setOutbox` | 生产参数 |
| `toRegistry()` | `List<String>` -> `BizCodeRegistry` |
| `toOutboxConfig()` | YAML 参数 -> `OutboxConfig` |
| `Outbox` 内部 getter/setter | 绑定 linger/batch/buffer/scan/retry/senderThreads |

## 4. `DemoConfigLoader`

| 方法 | 作用 |
|---|---|
| `load(Resource)` | 读取 YAML，绑定 `tx` 前缀为 `DemoProperties` |

流程：

```text
YamlPropertySourceLoader.load
→ MutablePropertySources
→ Binder.bind("tx", DemoProperties)
→ 返回配置对象
```

## 5. `AssignLeadCommand`

```java
public record AssignLeadCommand(long leadId, long salesId, String requestId) {
    public AssignLeadCommand {
        if (leadId <= 0 || salesId <= 0) {
            throw new IllegalArgumentException("leadId/salesId must be positive");
        }
        if (requestId == null || requestId.isBlank()) {
            throw new IllegalArgumentException("requestId must not be blank");
        }
    }
}
```

输入：

```text
leadId=1001
salesId=2002
requestId=req-001
```

结果：

```text
合法命令对象
leadId/salesId 非正 -> IllegalArgumentException
requestId 空 -> IllegalArgumentException
```

## 6. `LeadAssignService`

```java
public class LeadAssignService {

    private final LeadRepository leadRepository;
    private final OutboxPublisher outboxPublisher;

    public LeadAssignService(
            LeadRepository leadRepository,
            OutboxPublisher outboxPublisher) {
        this.leadRepository = leadRepository;
        this.outboxPublisher = outboxPublisher;
    }

    @Transactional
    public void assign(AssignLeadCommand command) {
        leadRepository.assign(command.leadId(), command.salesId());

        outboxPublisher.publish(new BusinessEvent(
                "lead-assigned:" + command.leadId() + ":" + command.requestId(),
                "lead",
                String.valueOf(command.leadId()),
                "LEAD_ASSIGNED",
                "{\"leadId\":" + command.leadId()
                        + ",\"salesId\":" + command.salesId() + "}"
        ));
    }
}
```

### 逐步

1. `@Transactional`

```text
最外层业务事务
业务表和 t_local_message 必须同一事务
```

2. `leadRepository.assign`

```text
更新线索归属
```

3. 生成 eventKey

```text
lead-assigned:{leadId}:{requestId}
```

`requestId` 保证同一请求重试时 eventKey 不变。

4. `publish`

```text
写入 t_local_message(INIT)
不写 Redis
```

### 最终结果

```text
业务表已更新
t_local_message 有一条 INIT
事务提交后由 OutboxScanner 异步发送
```


## 10. 业务方看完要记住

```text
业务方只写两个东西：业务表 + Outbox 事件
事件写入必须和业务表在同一个 MySQL 事务
不要直接写 Redis Stream
不要自己维护发送线程
```
