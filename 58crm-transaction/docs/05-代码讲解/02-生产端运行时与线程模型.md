# 生产端运行时与线程模型

> 读完你能做什么：说清 Producer 启动后有哪些线程、消息怎么走、失败怎么走、分片怎么分。

## 1. 线程图

```text
OutboxProducer
  │
  ├── tx-outbox-scanner（1 个）
  │      └── 定时扫 MySQL INIT
  │
  └── tx-outbox-sender-N（N 个）
         ├── Sender-0：lead, contract
         ├── Sender-1：quota, order
         └── ...
```

N：

```text
N = min(config.senderThreads, registry.bizCodes().size())
```

## 2. 运行时总图

```text
业务事务
  │
  ├── 业务表 UPDATE
  └── t_local_message(INIT)
  COMMIT
        │
        ▼
OutboxScanner
  每 10ms 扫 INIT
  校验 Registry
  放入 OutboxBuffer
        │
        ▼
OutboxBuffer
  按 bizCode 分桶
  条数 + 字节双重容量
  满时阻塞 Scanner
        │
        ▼
OutboxSender shard
  只取自己 assignedBizCodes
  10ms 窗口
  最多 256 条
        │
        ├── InterceptorChain.onSend
        ├── Partitioner
        ├── Serializer
        └── RedisStreamPublisher.publish（pipeline）
        │
        ▼
Redis Stream tx:stream:{bizCode}
        │
        ▼
MySQL markSentBatch：INIT -> SENT
```

## 3. 扫描和发送为什么分开

如果一起做：

```text
扫 MySQL
→ 等 Redis
→ 写 MySQL
→ 再扫
```

问题：

```text
Redis 抖动直接拖慢扫描
数据库扫描和网络 I/O 互相影响
没有内存缓冲，流量峰值直接打到 Redis
```

分开后：

```text
Scanner 只做 DB -> 内存
Sender 只做内存 -> Redis -> DB
```

## 4. 队列怎么选

`OutboxRecord.bizCode()` 决定队列：

```text
bizCode=lead  → queues["lead"]
bizCode=quota → queues["quota"]
```

不是按：

```text
msgId   太散，无法批量
bizId   太多，队列爆炸
```

## 5. Sender shard 怎么分

```text
bizCode 排序
→ 轮询分配
→ shardCount = min(senderThreads, bizCodeCount)
```

5 个 bizCode，3 个 shard：

```text
Shard-0: contract, order
Shard-1: customer, quota
Shard-2: lead
```

一个 bizCode 只属于一个 shard：

```text
同一业务线不会被两个 Sender 并发发送
```

## 6. 10ms 窗口与 256 批量

Sender 取第一批后：

```text
deadline = now + linger
while batch < batchSize:
  poll assignedBizCodes until deadline
```

含义：

```text
不是有第一条就立刻发
而是在 10ms 内尽量聚合
```

批量上限：

```text
单次最多 256 条
```

## 7. 发送失败路径

### 单条/整批 XADD 失败

```text
publish 失败
→ 二分拆批
→ 好消息继续成功
→ 单条坏消息 markFailed
→ 超过 maxRetries -> DEAD
```

### 序列化失败

```text
publishOrSplit 内抛异常
→ 拆批
→ 单条失败
```

### markSentBatch 失败

```text
XADD 已成功
状态仍 INIT
→ 下一轮重复 XADD
→ 消费方幂等兜底
```

## 8. 超大消息

```text
record bytes > maxBytes
→ MessageTooLargeException
→ Scanner 直接 markFailed(maxRetries=1)
→ DEAD
```

不会：

```text
永久阻塞 Scanner
```

## 9. 未知 bizCode

```text
Registry 校验失败
→ Scanner 直接 DEAD
→ 不创建孤儿 Stream
```

## 10. 状态机

```text
INIT
  │
  ├── XADD 成功 ──> SENT（主链路终态）
  │
  ├── XADD 失败/序列化失败
  │      └── retry_count+1
  │            ├── 未超限 -> INIT（等 next_retry_at）
  │            └── 超限 -> DEAD
  │
  └── 未知 bizCode / 超大消息
         └── DEAD
```

生产方没有：

```text
CONSUMED
消费租约
consumer_id
```

## 11. 关闭流程

```text
OutboxProducer.close
  ├── running=false
  ├── scannerExecutor.shutdownNow
  ├── senderExecutor.shutdownNow
  ├── awaitTermination(5s)
  └── interceptors.close
```
