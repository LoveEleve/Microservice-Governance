# 配置与持久化：逐行源码讲解

> 目标：不只知道“有这个类”，而是知道每个方法输入什么、做了什么、输出什么、失败什么。
> 机械 getter/setter/record accessor 已在 `01-生产端类与方法全解` 列出；本文讲有逻辑的代码。

## 1. `BizCodeConfig`

```java
public record BizCodeConfig(String bizCode) {
    public BizCodeConfig {
        if (bizCode == null || bizCode.isBlank()) {
            throw new IllegalArgumentException("bizCode must not be blank");
        }
    }
}
```

逐行：

| 行 | 做什么 |
|---|---|
| `record BizCodeConfig(String bizCode)` | 编译器生成字段、规范构造器、`bizCode()`、equals/hashCode/toString |
| `public BizCodeConfig {` | 紧凑构造器，参数 `bizCode` 是隐式参数 |
| `if (bizCode == null || bizCode.isBlank())` | 拒绝 null、空串、纯空格 |
| `throw ...` | 配置错误在启动期暴露 |
| `}` | 编译器在末尾自动执行 `this.bizCode = bizCode` |

结果：

```text
合法：new BizCodeConfig("lead")
非法：new BizCodeConfig(" ") -> IllegalArgumentException
```

## 2. `BizCodeRegistry` 构造器

```java
public BizCodeRegistry(Collection<BizCodeConfig> configs) {
    if (configs == null || configs.isEmpty()) {
        throw new IllegalArgumentException("bizCode configs must not be empty");
    }
    Map<String, BizCodeConfig> byCode = new LinkedHashMap<>();
    for (BizCodeConfig config : configs) {
        BizCodeConfig previous = byCode.putIfAbsent(config.bizCode(), config);
        if (previous != null) {
            throw new IllegalArgumentException("duplicate bizCode: " + config.bizCode());
        }
    }
    this.configs = Map.copyOf(byCode);
}
```

### 输入

```text
Collection<BizCodeConfig>
```

### 逐步做了什么

1. `configs == null || isEmpty`

```text
没有白名单 -> 直接失败
```

2. 创建 `LinkedHashMap`

```text
key = bizCode
value = BizCodeConfig
LinkedHashMap 保留配置顺序
```

3. 遍历配置

```java
byCode.putIfAbsent(config.bizCode(), config)
```

`putIfAbsent` 的语义：

```text
key 不存在 -> 放入，返回 null
key 已存在 -> 不覆盖，返回旧值
```

4. 发现旧值

```text
同一个 bizCode 出现两次
-> 配置错误
-> 抛 IllegalArgumentException
```

5. `Map.copyOf(byCode)`

```text
复制为不可变 Map
启动后外部再改集合，不影响 registry
```

### 输出

```text
成功：不可变 Map<String, BizCodeConfig>
失败：IllegalArgumentException
```

### 例子

```text
[lead, quota] -> {lead=..., quota=...}
[lead, lead] -> duplicate bizCode: lead
[] -> bizCode configs must not be empty
```

## 3. `BizCodeRegistry.from`

```java
public static BizCodeRegistry from(Map<String, BizCodeConfig> configs) {
    for (Map.Entry<String, BizCodeConfig> entry : configs.entrySet()) {
        if (!entry.getKey().equals(entry.getValue().bizCode())) {
            throw new IllegalArgumentException(
                    "bizCode key mismatch: " + entry.getKey()
                            + " != " + entry.getValue().bizCode());
        }
    }
    return new BizCodeRegistry(configs.values());
}
```

输入：

```text
Map<配置 key, BizCodeConfig>
```

为什么要校验：

```text
YAML/Map 的 key 是 lead
value.bizCode 却是 quota
-> 实际注册的是 quota
-> key lead 被悄悄忽略
```

输出：

```text
合法 Map -> BizCodeRegistry
key/value 不一致 -> IllegalArgumentException
```

## 5. `BizCodeRegistry.require`

```java
public BizCodeConfig require(String bizCode) {
    BizCodeConfig config = configs.get(bizCode);
    if (config == null) {
        throw new UnknownBizCodeException(bizCode);
    }
    return config;
}
```

输入：

```text
bizCode
```

逻辑：

```text
查 Map
不存在 -> UnknownBizCodeException
存在 -> 返回配置
```

调用点：

## 8. `MybatisOutboxPublisher.publish`

```java
@Transactional(propagation = Propagation.MANDATORY)
public String publish(BusinessEvent event) {
    bizCodeRegistry.require(event.bizCode());

    String msgId = UUID.randomUUID().toString();
    LocalDateTime now = LocalDateTime.now();

    LocalMessageEntity entity = new LocalMessageEntity();
    entity.setMsgId(msgId);
    entity.setEventKey(event.eventKey());
    entity.setBizCode(event.bizCode());
    entity.setBizId(event.bizId());
    entity.setEventType(event.eventType());
    entity.setPayload(event.payload());
    entity.setStatus(MessageStatus.INIT.name());
    entity.setRetryCount(0);
    entity.setCreatedAt(now);
    entity.setUpdatedAt(now);

    localMessageMapper.insert(entity);
    return msgId;
}
```

步骤：

1. `@Transactional(MANDATORY)`

```text
调用方必须已有事务
否则 Spring 抛 IllegalTransactionStateException
```

2. `registry.require`

```text
未知 bizCode 直接拒绝
不写消息
```

3. `UUID`

```text
生成 msgId
```

4. 组装 Entity

```text
status = INIT
retryCount = 0
createdAt/updatedAt = now
```

5. `insert`

```text
写入 t_local_message
```

输出：

```text
成功 -> msgId
未知 bizCode -> UnknownBizCodeException
eventKey 重复 -> MySQL 唯一键异常
没有外层事务 -> IllegalTransactionStateException
```

## 9. `MybatisLocalMessageRepository.findRelayCandidates`

```java
public List<LocalMessage> findRelayCandidates(int limit) {
    int safeLimit = Math.max(1, Math.min(limit, MAX_BATCH_SIZE));
    LocalDateTime now = LocalDateTime.now();

    LambdaQueryWrapper<LocalMessageEntity> query = Wrappers.lambdaQuery();
    query.eq(LocalMessageEntity::getStatus, MessageStatus.INIT.name())
            .and(wrapper -> wrapper
                    .isNull(LocalMessageEntity::getNextRetryAt)
                    .or(retry -> retry.le(LocalMessageEntity::getNextRetryAt, now)))
            .orderByAsc(LocalMessageEntity::getCreatedAt)
            .last("LIMIT " + safeLimit);
    ...
}
```

输入：

```text
limit
```

逻辑：

```text
1. limit 夹在 1~1000
2. 只查 status=INIT
3. next_retry_at 为 null 或已到期
4. 按 created_at 升序
5. LIMIT
6. Entity -> LocalMessage
```

输出：

```text
待投递消息列表
```

为什么不查 SENT：

```text
SENT 已写入 Stream
生产方不能再靠超时重发
```

## 10. `markSentBatch`

```java
public int markSentBatch(List<LocalMessage> messages, Instant nextRetryAt) {
    Map<String, List<String>> byBizId = new LinkedHashMap<>();
    for (LocalMessage message : messages) {
        if (message.status() != MessageStatus.INIT) {
            continue;
        }
        byBizId.computeIfAbsent(message.bizId(), ignored -> new ArrayList<>())
                .add(message.msgId());
    }
    ...
}
```

步骤：

1. 只处理 `INIT`
2. 按 `bizId` 分组
3. 每组执行：

```text
UPDATE t_local_message
SET status='SENT', retry_count=0, ...
WHERE biz_id=? AND msg_id IN (...) AND status='INIT'
```

输出：

```text
实际 UPDATE 行数
```

为什么要按 bizId：

```text
分片键是 biz_id
带分片键才能单片路由
```
